# Uber_Analysis_Project
Uber Analysis using SQL and Power Bi

## SQL Techniques

- CTEs (Common Table Expressions)
- Window Functions: `ROW_NUMBER()`, `RANK()`, `DENSE_RANK()`, `NTILE()`, `LAG()`, `LEAD()`
- Running Totals & Rolling Analysis
- Date & Time Analysis
- Subqueries
- Conditional Aggregation
- Customer Segmentation
- Ranking & Comparative Analysis

## Key Analysis

- Analyzed **148K+ ride bookings** to evaluate revenue, booking volume, customer behavior, and operational performance.
- Identified **high-value customers** and analyzed customer revenue contribution using CTEs, window functions, and Pareto analysis.
- Calculated **Month-over-Month (MoM) revenue growth** and rolling revenue to identify business growth trends.
- Analyzed **vehicle-type performance** using booking volume, revenue, average booking value, and cancellation rates.
- Identified **consecutive-month customers** and consecutive ride-day streaks to understand customer engagement and retention.
- Ranked **pickup locations and routes by revenue** to identify high-performing demand zones.
- Analyzed **payment-method preferences** across different vehicle categories.
- Identified **cancellation patterns and reasons** to highlight potential operational issues.
- Calculated **average time between customer bookings** using `LAG()` and `TIMESTAMPDIFF()` to understand ride frequency.
- Used **conditional aggregation** to calculate KPIs such as cancellation rate and revenue contribution.
